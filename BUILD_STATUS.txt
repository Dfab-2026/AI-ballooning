    python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
  
  Terminal 2 (Frontend):
    cd frontend
    npm run dev
  
  Then open: http://localhost:5174 (or shown port)

Health & Status:
  GET /health                           Check backend status

Projects:
  POST /upload                          Upload drawing files
  GET /project/{project_id}            Get project data
  DELETE /project/{project_id}         Delete project
  GET /project/{project_id}/zip        Download all as ZIP

Analysis:
  POST /analyze                        Start analysis
  GET /analyze/{project_id}            Get analysis progress

Export:
  GET /drawing/{id}/pdf                Export single PDF
  GET /project/{id}/excel              Export Excel reports

Port already in use?
  → Frontend auto-selects next port (5174, 5175, etc)
  → Manual port: npm run dev -- --port 3000

Backend won't start?
  → Check Python: python --version
  → Check dependencies: pip install -r requirements.txt
  → Check .env file has GEMINI_API_KEY

Frontend won't connect to backend?
  → Ensure backend is running: http://localhost:8000/docs
  → Check vite.config.js proxy settings
  → Check browser console for CORS errors

AI analysis fails?
  → Verify GEMINI_API_KEY in backend/.env
  → Check API quota: https://ai.google.dev
  → Ensure PDF is not corrupted
