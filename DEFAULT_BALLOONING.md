# Default ballooning

The normal balloon circle size and ~1 cm leader style are unchanged.

Only the measurement-side clearance was increased so the arrow tip stops with a small visible white-space gap before the dimension/callout text.


## Circle clearance rule
Numbered circles are rendered without leader lines/arrows. Auto-placement verifies a white safety halo around each circle using drawing pixels and chooses the nearest clear position in this order: above, side, then below. Circles must not touch measurement characters or CAD linework.
