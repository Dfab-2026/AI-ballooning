# 0.5 cm balloon leader + cursor correction

- The ~0.5 cm increase applies only to drawing balloon leader placement.
- Automatic and manual drawing balloons use the longer leader spacing.
- The normal workspace cursor is restored; the D-circle cursor is not used.
- While Add Balloon mode is active over the drawing, the cursor becomes only a rotated diagonal arrow with its tip as the click hotspot.
- Existing Excel, PDF, ZIP, sequencing, inspection-template and Vercel behavior is unchanged.
