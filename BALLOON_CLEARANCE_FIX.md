# Balloon clearance fix

Only balloon placement spacing was changed in this build.

- Automatic balloons now start farther beside the detected measurement/callout.
- A larger minimum horizontal clearance keeps the circle from touching or covering dimension text.
- The leader remains on the same line and points back to the detected characteristic.
- Manual-added balloons use the same wider side offset.
- Excel, PDF, ZIP, sequencing, report-template and all other behavior is unchanged.
