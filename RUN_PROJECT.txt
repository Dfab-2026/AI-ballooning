LOCAL TEST
1. Copy .env.example to .env and put your real GEMINI_API_KEY in .env.
2. Create/activate a virtual environment.
3. pip install -r requirements.txt
4. Backend: python -m uvicorn backend.app.core:app --host 127.0.0.1 --port 8000 --reload
5. Frontend (second terminal): python -m http.server 5500
6. Open http://127.0.0.1:5500
7. Backend health: http://127.0.0.1:8000/health

VERCEL
1. Repository root must directly contain api/, backend/, assets/, index.html and requirements.txt.
2. Root Directory: ./
3. Do not add a custom Build Command, Output Directory, or Install Command.
4. Add GEMINI_API_KEY in Vercel Environment Variables.
5. No vercel.json is required for this structure.
6. After deploy test: /api/health
