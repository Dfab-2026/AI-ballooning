# Balloon leader + D cursor update

- Generated balloon leader placement is extended by approximately 0.5 cm (about 19 px at 96 DPI) compared with the previous approved layout.
- Arrow-tip clearance from drawing dimensions is unchanged, so the extra length is added on the balloon-circle side rather than covering measurement text.
- Manual balloon placement uses the same increased spacing.
- The engineering cursor remains the requested **D balloon** and its leader graphic is longer to match the drawing balloon style.
- AI targeting explicitly prefers a dimension/extension/measurement leader line immediately beside the measurement, not the measurement characters.
- Excel, PDF/ZIP export, sequencing, signatures and report behavior are unchanged.
